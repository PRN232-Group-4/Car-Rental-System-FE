# Admin: menu, biểu mẫu popup và loading chuyển trang

- Đưa Tổng quan lên đầu menu; thêm nút đóng/mở sidebar desktop và giữ menu mobile.
- Mở popup thêm phương tiện ngay tại danh sách hoặc Tổng quan, giữ bộ lọc/phân trang và tải lại danh sách sau khi tạo thành công.
- Dùng chung hộp thoại cho danh mục, nhân sự, phiếu bảo trì và ca tài xế: focus trong popup, Escape, nút đóng, cuộn form dài và chặn đóng khi đang lưu.
- Giữ validation tiếng Việt dưới trường nhập và dữ liệu khi API trả lỗi.
- Thêm loading cho điều hướng bằng link, router và lịch sử trình duyệt; bỏ qua cùng URL, anchor và liên kết ngoài. Trạng thái tải API của từng trang tiếp tục hiển thị riêng.
- Thêm kiểm thử hồi quy trình duyệt với API giả lập cho menu desktop/mobile, popup, validation và chuyển trang.
